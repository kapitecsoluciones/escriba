# Changelog

## 0.2.0 — 2026-08-20

First public release.

- Records microphone and system audio together, so video calls work.
- Speaker attribution from the two separate tracks, without a diarization model.
- Local transcription with whisper.cpp.
- Minute drafted with the client's own file as context, plus internal notes.
- Swappable writing engine: Claude Code, your own API key, or Ollama.
- Branded PDF export and a per-client dossier PDF.
- Global shortcut, level meters, and a search across every transcript.
